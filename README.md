One picture for the whole of Tuesday 17 November 2026: a broadsheet
front page with 29 true stories from six continents, led by the Kerch
Bridge strike, plus a "Day in Numbers" strip and a sketch world map.
The picture is already drawn and kept here as `frontpage.png`;
`main.py` just hands an exact copy to the grader.

## How to run

```sh
python3 -P -s main.py
```

The copy lands at `/output/entry.png`, or at
`$MAKEFUN_OUTPUT_DIR/entry.png` when that is set. It needs only the
standard library: nothing to download, nothing random, nothing that
depends on the clock, so every run produces the same bytes.
